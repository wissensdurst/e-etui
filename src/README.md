# Artičok Landing Page

This project is a simple landing page for the Artičok restaurant located in Split. It includes links to the restaurant's official website and a Google review page.

## Project Structure

```
articok-landing
├── index.html        # Main HTML document for the landing page
├── css
│   └── styles.css    # Styles for the landing page
├── js
│   └── main.js       # JavaScript functionality for the landing page
├── package.json      # Configuration file for npm
├── .gitignore        # Files and directories to be ignored by version control
└── README.md         # Documentation for the project
```

## Links

- [Artičok](https://www.articok-restaurant.com) - Official website of the restaurant in Split.
- [Review us on Google](https://www.google.com/maps/place/Arti%C4%8Dok) - Submit your reviews on Google.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd articok-landing
   ```
3. Install dependencies (if any):
   ```
   npm install
   ```
4. Open `index.html` in your browser to view the landing page.
